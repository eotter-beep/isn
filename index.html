02 / HOW IT WORKS

Storage, distributed
by design.

ISN turns a single write into verifiable, recoverable pieces that can move across an open network.

01

Store

const id = await isn.put(data);

Your application writes through the browser interface.

02

Split

Data is chunked, hashed, and encrypted before it travels.

03

Distribute

◆◆◆

Chunks are stored across independent reachable nodes.

04

Recover

const data = await isn.get(id);

Replicas answer the read. Missing pieces can be rebuilt.
